# Master Pedagogical Rubric
1. **The "Why -> What -> How" Progression:** Never introduce a technical mechanism without first establishing the historical or technical problem that made it necessary.
2. **Progressive Decomposition:** Never cram complex ideas into a single text-heavy slide. Decompose them visually.
3. **The Rule of 6:** Maximum 6 words per bullet point, maximum 4 bullet points per slide. 
4. **Local Analogies:** Embed real-world physical analogies anchored to regional contexts (e.g., agriculture, pipeline telemetry) frequently.
5. **No Placeholders:** All generated code labs must be fully functional. No "TODO" stubs.
